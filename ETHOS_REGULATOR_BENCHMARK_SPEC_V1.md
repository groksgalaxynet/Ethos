# ETHOS Regulator Benchmark V1

Research-only benchmark for Greed, Pride, and Envy. It tests observable cues, context/provenance controls, lexical pairs, structured fields, mixed-regulator evidence, and boundary behavior. It is not proof of moral correctness or a tuning authority.

Every case preserves exact proposal fields, category, label/rationale/confidence, reviewer (`PROJECT_REVIEW_V1`), source, optional pair, current measurement, decision, and policy IDs. Only strong `BENIGN_ALLOW` and `SHOULD_BLOCK` labels enter confusion metrics. All other labels remain review-only.

The runner uses the current gate with a temporary evidence path. It cannot change normal evidence, history, scars, thresholds, weights, vocabulary, or execution behavior. Paired-case deltas measure lexical/provenance sensitivity only.
